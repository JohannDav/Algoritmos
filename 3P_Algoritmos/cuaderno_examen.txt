
🔍 ALGORITMOS DE BÚSQUEDA
1. Búsqueda Secuencial (Lineal)
Cómo funciona:
Recorre el arreglo elemento por elemento desde el principio hasta encontrar lo que busca.

Ejemplo visual:

text
Arreglo: [3, 7, 1, 9, 5]  Buscar: 9

Paso 1: [3] → ¿es 9? NO
Paso 2: [7] → ¿es 9? NO
Paso 3: [1] → ¿es 9? NO
Paso 4: [9] → ¡ENCONTRADO!
Ventaja: Funciona aunque el arreglo NO esté ordenado
Desventaja: Lento para arreglos grandes (O(n))

2. Búsqueda Binaria
Cómo funciona:
Solo funciona con arreglos ordenados. Divide el arreglo a la mitad repetidamente.

Ejemplo visual:

text
Arreglo ordenado: [1, 3, 5, 7, 9, 11, 13]  Buscar: 7

Paso 1: [1, 3, 5, 7, 9, 11, 13] → mitad = 7
        ↓ comparo 7 con 7 → ¡ENCONTRADO!

Buscar: 3

Paso 1: [1, 3, 5, 7, 9, 11, 13] → mitad = 7
        3 < 7 → busco en mitad izquierda [1, 3, 5]

Paso 2: [1, 3, 5] → mitad = 3
        3 = 3 → ¡ENCONTRADO!
Ventaja: Muy rápido O(log n)
Desventaja: Requiere que los datos estén ordenados

📊 ALGORITMOS DE ORDENAMIENTO
1. Burbuja (Bubble Sort)
Cómo funciona:
Compara elementos adyacentes y los intercambia si están en orden incorrecto. Los elementos más grandes "burbujean" hacia el final.

Ejemplo visual:

text
Arreglo: [5, 2, 4, 1, 3]  (Ordenar ascendente)

Pasada 1:
[5, 2] → 5>2 → intercambia → [2, 5, 4, 1, 3]
[5, 4] → 5>4 → intercambia → [2, 4, 5, 1, 3]
[5, 1] → 5>1 → intercambia → [2, 4, 1, 5, 3]
[5, 3] → 5>3 → intercambia → [2, 4, 1, 3, 5] ← 5 ya está en su lugar

Pasada 2:
[2, 4] → 2<4 → no cambia → [2, 4, 1, 3, 5]
[4, 1] → 4>1 → intercambia → [2, 1, 4, 3, 5]
[4, 3] → 4>3 → intercambia → [2, 1, 3, 4, 5]

Pasada 3:
[2, 1] → 2>1 → intercambia → [1, 2, 3, 4, 5] ← ORDENADO!
2. Flotación (Burbuja mejorado)
Cómo funciona:
Similar a burbuja pero el bucle interno siempre empieza desde el principio. Los elementos más pequeños "flotan" hacia arriba.

Ejemplo visual:

text
Arreglo: [5, 2, 4, 1, 3]

Pasada 1:
[5,2] → intercambia → [2,5,4,1,3]
[5,4] → intercambia → [2,4,5,1,3]
[5,1] → intercambia → [2,4,1,5,3]
[5,3] → intercambia → [2,4,1,3,5]

Pasada 2: sigue hasta ordenar
3. Inserción (Insertion Sort)
Cómo funciona:
Toma un elemento y lo inserta en la posición correcta dentro de la parte ya ordenada.

Ejemplo visual:

text
Arreglo: [5, 2, 4, 1, 3]

Paso 1: [5, 2, 4, 1, 3] → toma 2 → inserta antes de 5 → [2, 5, 4, 1, 3]
Paso 2: [2, 5, 4, 1, 3] → toma 4 → inserta entre 2 y 5 → [2, 4, 5, 1, 3]
Paso 3: [2, 4, 5, 1, 3] → toma 1 → inserta al inicio → [1, 2, 4, 5, 3]
Paso 4: [1, 2, 4, 5, 3] → toma 3 → inserta entre 2 y 4 → [1, 2, 3, 4, 5]
Ideal para: Arreglos pequeños o casi ordenados

4. Selección (Selection Sort)
Cómo funciona:
Busca el elemento más pequeño y lo coloca al inicio, luego el segundo más pequeño, etc.

Ejemplo visual:

text
Arreglo: [5, 2, 4, 1, 3]

Paso 1: encontrar el menor (1) → intercambiar con posición 0 → [1, 2, 4, 5, 3]
Paso 2: encontrar el menor de [2,4,5,3] (2) → ya está → [1, 2, 4, 5, 3]
Paso 3: encontrar el menor de [4,5,3] (3) → intercambiar con posición 2 → [1, 2, 3, 5, 4]
Paso 4: encontrar el menor de [5,4] (4) → intercambiar con posición 3 → [1, 2, 3, 4, 5]
5. Shell Sort
Cómo funciona:
Es una mejora de inserción. Compara elementos separados por una "brecha" (gap) que se va reduciendo.

Ejemplo visual:

text
Arreglo: [8, 3, 6, 1, 7, 2, 5, 4]  n=8

Gap = 4 (n/2):
Comparo posiciones: 0-4, 1-5, 2-6, 3-7
[8,7] → intercambia → [7,3,6,1,8,2,5,4]
[3,2] → intercambia → [7,2,6,1,8,3,5,4]
[6,5] → intercambia → [7,2,5,1,8,3,6,4]
[1,4] → intercambia → [7,2,5,4,8,3,6,1]

Gap = 2:
Comparo posiciones con distancia 2
...

Gap = 1: (insercion normal) → arreglo ordenado
6. QuickSort
Cómo funciona:
Elige un "pivote", coloca los menores a la izquierda y mayores a la derecha, luego repite.

Ejemplo visual:

text
Arreglo: [8, 3, 6, 1, 7, 2, 5, 4]  pivote = 4 (último)

Partición: menores que 4 a la izquierda, mayores a la derecha
[3, 1, 2, 4, 8, 7, 6, 5]

Ahora ordenar recursivamente:
Izquierda [3,1,2] con pivote 2 → [1,2,3]
Derecha [8,7,6,5] con pivote 5 → [5,8,7,6] → [5,6,8,7] → [5,6,7,8]

Unir: [1,2,3,4,5,6,7,8]
Esquema visual:

text
        [8,3,6,1,7,2,5,4]
              ↓ pivote=4
    [3,1,2]  4  [8,7,6,5]
       ↓           ↓
    [1,2,3]     [5,6,7,8]
       ↓           ↓
    [1,2,3,4,5,6,7,8]
7. HeapSort
Cómo funciona:
Construye un "montículo" (heap) donde el padre siempre es mayor que los hijos, luego extrae la raíz repetidamente.

Ejemplo visual:

text
Arreglo: [4, 10, 3, 5, 1]

Paso 1: Construir MAX-HEAP (árbol donde padre > hijos)
        
        10
       /  \
      5    4
     / \
    1   3

Paso 2: Extraer raíz (mayor) y reordenar
Extraer 10 → [10]
Reordenar: [5,3,4,1] → [5,4,3,1]
Extraer 5 → [10,5]
Reordenar: [4,3,1]
Extraer 4 → [10,5,4]
...

Resultado: [1,3,4,5,10] ascendente
8. Timsort
Cómo funciona:
Combina Insertion Sort + Merge Sort. Divide en "runs" (subarreglos), los ordena con inserción y luego los fusiona.

Esquema visual:

text
Arreglo: [5,2,8,1,9,3,7,4,6]

Paso 1: Dividir en runs de tamaño RUN (ej: 4)
Run1: [5,2,8,1] → insertion → [1,2,5,8]
Run2: [9,3,7,4] → insertion → [3,4,7,9]
Run3: [6] → [6]

Paso 2: Fusionar runs (merge)
[1,2,5,8] + [3,4,7,9] = [1,2,3,4,5,7,8,9]
[1,2,3,4,5,7,8,9] + [6] = [1,2,3,4,5,6,7,8,9]
¿Por qué es eficiente? Aprovecha que la inserción es rápida en subarreglos pequeños.

9. Introsort
Cómo funciona:
Comienza como QuickSort, pero si se vuelve ineficiente (mucha recursión), cambia a HeapSort, y para subarreglos pequeños usa InsertionSort.

Esquema visual:

text
Arreglo grande
      ↓
  QuickSort (rápido normalmente)
      ↓
¿Demasiada recursión? (profundidad > 2*log(n))
      ↓ SÍ
  HeapSort (garantiza O(n log n))
      ↓
Subarreglo pequeño (≤ 16 elementos)
      ↓
  InsertionSort (rápido en pequeños)
Visual del cambio:

text
QuickSort →→→ (si es lento) →→→ HeapSort
     ↓
InsertionSort (para fragmentos pequeños)
📈 COMPLEJIDADES

Búsqueda Binaria	O(1)	O(log n)	O(log n)
Burbuja	O(n)	O(n²)	O(n²)
Flotación	O(n)	O(n²)	O(n²)
Inserción	O(n)	O(n²)	O(n²)
Selección	O(n²)	O(n²)	O(n²)
Shell	O(n log n)	O(n^(3/2))	O(n²)
QuickSort	O(n log n)	O(n log n)	O(n²)
HeapSort	O(n log n)	O(n log n)	O(n log n)
Timsort	O(n)	O(n log n)	O(n log n)
Introsort	O(n log n)	O(n log n)	O(n log n)
🎯 ¿CUÁL USAR?
Situación	Recomendación
Arreglo muy pequeño (<50)	Inserción o Selección
Arreglo casi ordenado	Inserción
Arreglo grande y desordenado	QuickSort, HeapSort, Timsort
Necesitas garantía de tiempo	HeapSort, Timsort, Introsort
Datos con patrones (parcialmente ordenados)	Timsort
Lenguaje con sort() incorporado	Timsort (Python), Introsort (C++)
